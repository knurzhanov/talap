# TALAP - Образовательная Экосистема ТиПО

Современный корпоративный портал для управления экосистемой Технического и Профессионального Образования (ТиПО). Проект представляет собой единую мастер-систему (MDM) для сбора данных колледжей и их интеграции с внешними платформами через REST API.

## 🚀 Основные возможности

- **Единый каталог платформ**: Bento-интерфейс для доступа к 9 подсистемам (Конструктор ОП, Реестр, Карта педагогов и др.).
- **Мастер-данные (MDM)**: Централизованный сбор данных о колледжах, преподавателях и студентах.
- **Ролевая модель**: 
  - **Кабинет Колледжа**: Заполнение паспорта организации, ведение реестра ОП, внутренняя статистика и рейтинг.
  - **Кабинет Администратора**: Глобальный мониторинг, управление API-интеграциями, модерация заявок от учебных заведений.
- **Интеграция**: Спроектированная архитектура для обмена данными с дочерними платформами.

## 🛠 Технологический стек

- **Core**: React 18, Vite.
- **Маршрутизация**: React Router DOM.
- **Дизайн**: Vanilla CSS (Enterprise Flat Design), Lucide Icons.
- **Интерактив**: Кастомные графики, сложные формы с валидацией, прелодеры и анимации входа.

## 📦 Структура проекта

- `/src/pages`: Модульные страницы кабинетов и публичной части.
- `/src/layouts`: DashboardLayout с поддержкой боковой навигации и ролей.
- `/src/components`: UI-компоненты (Header, Footer, Bento-grid и др.).
- `/src/assets`: Фирменные медиа-ресурсы.

## 🔧 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build
```

## 🔒 Безопасность
Проект спроектирован с учетом требований по защите персональных данных педагогов и студентов. Поддерживает интеграцию с SSO (Single Sign-On).
